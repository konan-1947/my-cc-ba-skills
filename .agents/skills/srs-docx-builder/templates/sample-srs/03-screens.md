## 3. Functional Requirements

### 3.1 Lesson

#### 3.1.1 Create lesson

This screen allows the teacher to set up the curriculum context so the AI system can generate a draft lesson plan aligned with MOET Official Dispatch No. 5512.

**Mapped Use Case(s):**
- UC-05: Create Lesson Plan

The Lesson Plan Creation screen allows the Teacher to:
- Select the exact pedagogical context through cascading dropdowns (Subject, Grade, Chapter, Lesson).
- Enter additional instructions for the AI to customize the learning objectives.
- Submit the generation request and continue in the Lesson Plan Editor.

**Field Description**

| Field Name | Description |
|---|---|
| Subject | Allows the user to select the subject for which the lesson plan will be created. |
| Grade | Allows the user to select the grade level associated with the selected subject. |
| Create Lesson Plan | Submits the selected teaching content and instructions to the AI. |
